# 我的知识库

这里用于沉淀你在 ChatGPT 中产生的学习问答。同步后的笔记会先匹配已有分类，确实不合适时才自动创建新分类。

## 日常使用

1. 在项目目录运行 `pnpm dev:sync`，同时启动 VuePress 和本地同步服务。
2. 打开 ChatGPT，完成一轮问答。
3. 点击页面右下角的知识库按钮。
4. 笔记会出现在左侧的“ChatGPT 问答”目录中。

扩展的设置按钮中可以开启“回答完成后自动同步”。建议先使用手动同步，确认笔记内容合适后再开启自动模式。

::: warning 发布前检查
同步内容默认会进入 VuePress 构建结果。如果你以后把网站发布到公网，请先删除姓名、联系方式、公司内部信息、密钥和其他隐私内容。
:::
