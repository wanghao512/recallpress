# ChatGPT · VuePress 知识库助手

## 安装

1. 打开 Chrome，在地址栏输入 `chrome://extensions/`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择当前 `browser-extension` 文件夹。
5. 刷新已经打开的 ChatGPT 页面。

## 使用

先在项目目录启动网站和同步服务：

```bash
pnpm dev:sync
```

然后在 ChatGPT 页面点击右下角的知识库按钮。按钮空闲时会自动收成贴在右侧的圆形入口，鼠标移入或点击即可展开；设置面板打开、正在同步或键盘聚焦时不会自动收起。按钮旁的设置入口可以自定义知识库名称、检查服务连接状态，并开启或关闭自动同步。名称修改后，VuePress 的网站标题、首页、导航栏和侧边栏会一起更新。

圆形入口会显示同步状态：橙点代表存在尚未同步的完整回答，旋转光环代表正在同步，绿色勾代表成功，红色感叹号代表失败。展开后可点击图钉临时固定，固定状态只在当前页面有效，刷新后恢复自动吸附。

点击服务状态右侧的“API 设置”，可打开独立设置页。设置页支持修改 OpenAI 兼容 API 地址、模型、API Key 和 Chat Completions 路径，保存后立即生效；“测试连接”会发起一次最小模型请求。本地用量区域统计扩展产生的请求次数、输入 Token、输出 Token 和总 Token，账单与额度以你使用的模型服务商为准。

设置页顶部可以维护多个“知识库档案”，例如“学习笔记”“课程资料”和“项目文档”。每个档案分别保存 VuePress 项目目录、知识库名称、站点预览地址、模型配置和分类偏好；浮动面板与设置页都能一键切换。运行 `pnpm dev:sync` 时，切换档案会让本地预览自动重启到对应 VuePress 目录。移除档案只会删除助手中的配置记录，不会删除项目目录或文章。

“后续问题归档”支持两种模式：智能判断会让 LLM 查看现有分类后自主选择；固定分类会把后续新问题归入用户选定的现有分类。两种模式都会继续过滤提示词和非复习内容。

“同步范围”支持只同步最后一题和同步全部新题。最后一题模式只发送最近一组完整问答，适合长对话并作为默认选项；全部新题模式会扫描当前对话，再通过消息 ID 和内容去重，只补充知识库中尚未保存的题目。

“批量问答入库”可以预设一条对话规则，并粘贴编号列表、复习提纲或一整段混合问题素材。手动开始后，如果本地设置页已经配置并启用模型，扩展会先调用该模型提取、拆分和去重问题；没有可用模型时才按“一行一题”读取。随后扩展先把对话规则作为当前对话的第一条用户消息发送，再逐题等待 ChatGPT 回答完成；每题只有在成功同步后才会继续下一题。任务最多接受 100 道问题，可以随时停止，模型整理、发送或同步失败时都会暂停，不会静默改用按行解析。

ChatGPT 网页不允许扩展注入真正的 `system` 角色消息，因此这里的“对话规则”是普通用户消息，用于约束后续回答。建议在一个新对话中开始批量任务。问题素材和对话规则保存在浏览器本地，只有点击“整理并开始”后才会发送。

分类设置支持新建和重命名。新建分类后会自动选中；重命名只修改显示名称，分类目录和已有文章 URL 保持不变。

同步完成后可以通过提示中的“查看笔记”直接打开最新页面。遇到文字相同或语义相同的问题时，扩展会展示现有答案与本次答案，由你选择保留哪一个。

同步服务仅监听 `127.0.0.1:3847`，扩展不会读取 ChatGPT Cookie、密码或账号信息。
